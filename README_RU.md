# numbra

[English](README.md) | Русский

`numbra` — терминальная программа для регулярной тренировки ментальной арифметики. Она создаёт воспроизводимые примеры, проводит тренировку по этапам с таймером и хранит локальную статистику в SQLite.

## Требования и установка

Нужен Python 3.13 или новее. С `uv`:

```bash
uv tool install numbra
```

В рабочей копии репозитория установите зависимости разработки командой `uv sync --all-groups`, затем запускайте `uv run numbra`.

## Быстрый старт

```bash
numbra challenge
numbra results
```

Стандартная тренировка рассчитана на шесть минут и состоит из трёх этапов. `Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется.

## Команды

`numbra challenge` поддерживает параметры:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `--duration MINUTES` | из конфига (6) | Целевая общая длительность, минимум 1 |
| `--difficulty LEVEL` | `normal` | `easy`, `normal` или `hard` |
| `--seed INTEGER` | из конфига или генерируется | Воспроизводит этапы и последовательность примеров |
| `--operations LIST` | `+,-,*,/` | Список действий через запятую |
| `--stages INTEGER` | `3` | Точное количество этапов, минимум 1 |

Пример:

```bash
numbra challenge --duration 6 --difficulty normal --seed 42 --operations +,-,*,/ --stages 3
```

`numbra results --limit 10` показывает последние завершённые тренировки и агрегаты. Справка доступна через `numbra --help`, `numbra --version` и `--help` каждой команды.

Этапы бывают `fast`, `normal` и `slow`; стандартные лимиты ответа — 5, 10 и 15 секунд. Сложность задаёт детерминированное распределение: для трёх этапов easy — 0/1/2, normal — 1/1/1, hard — 2/1/0 этапов fast/normal/slow. При другом количестве этапов используется метод наибольших остатков, сохраняющий точное число этапов.

## Конфигурация и данные

При первом запуске numbra создаёт `numbra.toml`, `temps.json` и `design.toml` в системном каталоге пользовательской конфигурации. База `numbra.sqlite3` создаётся в системном каталоге пользовательских данных. Приоритет: параметры CLI, пользовательские файлы, встроенные значения. Ошибки TOML/JSON, неизвестные поля и неверные значения содержат имя файла и поля.

Полный пример настроек находится в `examples/numbra.toml`. Если seed не задан, для сессии создаётся новый случайный seed; он показывается пользователю и сохраняется вместе с результатами.

## Разработка

```bash
uv sync --all-groups
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv build
```

Ядро не зависит от Typer и Rich и пригодно для использования без CLI. Для таймера используется Prompt Toolkit, а SQLite предоставляется стандартной библиотекой Python. Облачной синхронизации, аккаунтов, GUI и сетевого API нет.
