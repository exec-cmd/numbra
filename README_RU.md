# numbra

[English](README.md) | Русский

`numbra` — терминальная программа для регулярной тренировки ментальной арифметики. Она создаёт воспроизводимые примеры, проводит тренировку по этапам с таймером и хранит локальную статистику в SQLite.

## Требования и установка

Нужен Python 3.13 или новее. С `uv`:

```bash
uv tool install .
```

Для установки готового wheel скачайте `numbra-<version>-py3-none-any.whl` из assets релиза и выполните:

```bash
uv tool install ./numbra-<version>-py3-none-any.whl
numbra --version
```

В рабочей копии репозитория установите зависимости разработки командой `uv sync --all-groups`, затем запускайте `uv run numbra`.

## Быстрый старт

```bash
numbra challenge
numbra results
```

Стандартная тренировка рассчитана на шесть минут и состоит из трёх этапов. `Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется.

## Команды

`numbra challenge` поддерживает параметры:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `-t, --duration MINUTES` | из конфига (6) | Целевая общая длительность, минимум 1 |
| `-d, --difficulty LEVEL` | `normal` | `very-easy`, `easy`, `normal`, `hard` или `very-hard` |
| `-S, --seed INTEGER` | из конфига или генерируется | Воспроизводит этапы и последовательность примеров |
| `-o, --operations LIST` | `+,-,*,/` | Список действий через запятую |
| `-n, --stages INTEGER` | `3` | Точное количество этапов, минимум 1 |
| `--strict` | выключен | Сразу проваливать пример при достижении лимита |
| `--cooldown SECONDS` | `2` | Пауза между примерами, от 1 до 3 секунд |

Пример:

```bash
numbra challenge --duration 6 --difficulty normal --seed 42 --operations +,-,*,/ --stages 3
```

`numbra results --limit 10` показывает последние завершённые тренировки и агрегаты. `numbra results --reset` очищает историю после подтверждения, а `numbra results --reset --yes` предназначен для скриптов. Справка доступна через `numbra --help`, `numbra --version` и `--help` каждой команды.

Этапы бывают `fast`, `normal` и `slow`; стандартные лимиты ответа — 5, 10 и 15 секунд. Правильный ответ получает число очков в зависимости от сложности примера; в обычном режиме до лимита начисляются все очки, затем действует линейное уменьшение до нуля на двойном лимите. Ввод после этого остаётся открытым. `--strict` превращает лимит в немедленный провал примера. `--cooldown` добавляет короткую паузу перед следующим примером.

Сложность задаётся профилем генератора: very-easy и easy используют два числа, normal смешивает два и три, hard — три и четыре, very-hard чаще использует четыре числа. Профиль также ограничивает разрядность и абсолютный размер промежуточных результатов. В одной тренировке одинаковые примеры не повторяются, а выбранные операции распределяются равномерно. Этапы `fast`, `normal` и `slow` меняют только лимит времени. Скобки используют стандартный приоритет арифметики. Небольшие степени (`^2` и `^3`) доступны на hard и very-hard только при явном выборе `^`. Деление всегда точное; отрицательные промежуточные результаты и ответы допускаются. Пределы профилей можно изменить в `numbra.toml`, включая `max_result`.

## Конфигурация и данные

При первом запуске numbra создаёт `numbra.toml`, `temps.json` и `design.toml` в системном каталоге пользовательской конфигурации. База `numbra.sqlite3` создаётся в системном каталоге пользовательских данных. Приоритет: параметры CLI, пользовательские файлы, встроенные значения. Ошибки TOML/JSON, неизвестные поля и неверные значения содержат имя файла и поля.

База и `numbra.log` находятся в системном каталоге пользовательских данных. Обычный лог пишется на уровне DEBUG, а `-v` дополнительно показывает сообщения в stderr. Если seed не задан, для сессии создаётся новый случайный seed; он показывается пользователю и сохраняется вместе с результатами.

## Разработка

```bash
uv sync --all-groups
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv build
uv tool install dist/numbra-0.1.0-py3-none-any.whl
numbra --version
```

Ядро не зависит от Typer и Rich и пригодно для использования без CLI. Живой обратный отсчёт реализован через Prompt Toolkit, SQLite и логирование используют стандартную библиотеку Python. Облачной синхронизации, аккаунтов, GUI и сетевого API нет.
