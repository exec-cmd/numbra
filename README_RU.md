# numbra

[English](README.md) | Русский

`numbra` — терминальный тренажёр для ежедневной тренировки скорости устного счёта. Он генерирует воспроизводимые примеры, проводит короткие этапы на время и хранит историю, личные рекорды и серию дней в локальной базе SQLite. Без аккаунтов и сети.

## Установка

Требуется Python 3.13 или новее. Из каталога проекта:

```bash
uv tool install .
numbra --version
```

Либо скачайте `numbra-<version>-py3-none-any.whl` из ассетов релиза и выполните `uv tool install ./numbra-<version>-py3-none-any.whl`.

## Быстрый старт

```bash
numbra challenge                 # шесть минут, три этапа, сложность normal
numbra challenge -d hard --strict
numbra challenge -o "*,/" -t 3   # только умножение и деление, три минуты
numbra challenge -o tricks       # приёмы устного счёта вроде 43 * 11 или 97 * 94
numbra tricks                    # все приёмы с правилом и примером
numbra results                   # история, личные рекорды, серия дней
```

`Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется. После каждой тренировки Numbra показывает среднее время верного ответа, личный рекорд для тех же настроек и текущую серию дней.
