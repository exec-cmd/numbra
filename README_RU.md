# numbra

[English](README.md) | Русский

`numbra` — терминальная программа для регулярной тренировки ментальной арифметики. Она создаёт воспроизводимые примеры, проводит тренировку по этапам с таймером и хранит локальную статистику в SQLite.

## Требования и установка

Нужен Python 3.13 или новее. С `uv`:

```bash
uv tool install .
```

Для установки готового wheel скачайте `numbra-<version>-py3-none-any.whl` из assets релиза и выполните:

```bash
uv tool install ./numbra-<version>-py3-none-any.whl
numbra --version
```

В рабочей копии репозитория установите зависимости разработки командой `uv sync --all-groups`, затем запускайте `uv run numbra`.

## Быстрый старт

```bash
numbra challenge
numbra results
```

Стандартная тренировка рассчитана на шесть минут и состоит из трёх этапов. `Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется.

## Команды

`numbra challenge` поддерживает параметры:

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `-t, --duration MINUTES` | из конфига (6) | Целевая общая длительность, минимум 1 |
| `-d, --difficulty LEVEL` | `normal` | `easy`, `normal`, `hard` или `very-hard` |
| `-S, --seed INTEGER` | из конфига или генерируется | Воспроизводит этапы и последовательность примеров |
| `-o, --operations LIST` | `+,-,*,/` | Через запятую: `+,-,*,/,sqrt,trig,log,power`; `^` — алиас `power` |
| `-n, --stages INTEGER` | `3` | Точное количество этапов, минимум 1 |
| `--strict` | выключен | Сразу проваливать пример при достижении лимита |
| `--cooldown SECONDS` | `2` | Пауза между примерами, от 1 до 3 секунд |
| `--advanced` / `--no-advanced` | из конфига | Включить все базовые операции и дополнительные темы / отключить дополнительные темы |
| `--identities` / `--no-identities` | из конфига | Независимо включить или выключить формулы сокращённого умножения |

При `-o "sqrt"` каждое задание содержит корень: самостоятельных арифметических заданий нет. Внутри тематических заданий используются выбранные базовые операторы, а если они не заданы — все четыре. `identities` не является значением `-o`; флаги `--sqrt`, `--trig`, `--log`, `--power` удалены.

Пример:

```bash
numbra challenge --duration 6 --difficulty normal --seed 42 --operations +,-,*,/ --stages 3
```

`numbra results --limit 10` показывает последние завершённые тренировки и агрегаты по операциям, темам и уровням. Сравнение с прежней тренировкой выполняется только при совпадении уровня, операций, этапов, режима strict, длительности, тем, версий генерации и подсчёта очков, а также отпечатка настроек; поэтому записи предыдущих версий генератора не считаются сопоставимыми с текущими тренировками. `numbra results --reset` очищает историю после подтверждения, а `numbra results --reset --yes` предназначен для скриптов. Справка доступна через `numbra --help`, `numbra --version` и `--help` каждой команды.

Типы этапов повторяются в порядке `slow → normal → fast`; стандартные лимиты ответа — 15, 10 и 5 секунд. Каждый этап получает сопоставимую долю активного времени, а примеры выбираются в статическом диапазоне трудоёмкости уровня: поздние этапы не становятся автоматически труднее. До временного штрафа за правильный ответ начисляется 1 очко и ещё 0,2 за каждый пункт трудоёмкости выше минимального. В мягком режиме очки линейно снижаются до нуля на двойном лимите, но ввод остаётся открытым. `--strict` завершает попытку при достижении лимита; `--cooldown` задаёт паузу перед следующим примером.

Сложность задаётся статическими пределами операндов и результатов, а также прозрачной шкалой трудоёмкости: easy — 1–2, normal — 2–5, hard — 4–8, very-hard — 6–12 единиц. По умолчанию используются 2 операнда для easy, 2–3 для normal и 3–4 для hard и very-hard. Каталоги задач конечны: после исчерпания выбранного каталога примеры повторяются, а программа выводит предупреждение. Арифметика следует стандартному приоритету операций, деление точное; в ответ можно ввести целое число или дробь, например `3/4`. Дополнительные темы по умолчанию выключены. Темы выбираются через `-o`, например `-o "sqrt,power"`. Степени ограничены показателями 2 и 3; `^` — алиас `power`. Формулы включаются отдельно через `--identities`. Для `easy` встроенный `max_result` равен 400; остальные профили по умолчанию не изменились.

Каталоги дополнительных тем ограничены: квадратные корни используют точные квадраты с корнями 2–20; степени — основания 2–20 и показатели 2 или 3; логарифмы — основания 2, 3, 5 или 10 и целые результаты от −3 до 4; тригонометрия — углы с точными рациональными значениями из таблиц; тождества — ограниченные шаблоны сумм и произведений. Знаменатель каждого точного рационального промежуточного значения, включая аргументы функций, не превышает 12; неподходящие кандидаты исключаются. Включённые темы должны помещаться в бюджет тренировки, иначе Numbra сообщает минимальную рекомендуемую длительность.

## Конфигурация и данные

При первом запуске numbra создаёт `numbra.toml`, `temps.json` и `design.toml` в системном каталоге пользовательской конфигурации. В таблице `[features]` пять тем (`sqrt`, `trig`, `log`, `power`, `identities`) выключены по умолчанию; параметра `advanced` в конфиге нет. Явный `-o` заменяет операции и темы из конфига, сохраняя независимую настройку identities. `--advanced` добавляет все базовые операции, темы и формулы; `--no-identities` отключает формулы независимо от порядка аргументов. Старое `difficulty = "very-easy"` преобразуется в `easy` с предупреждением, таблица `[difficulties.very-easy]` игнорируется с предупреждением. Существующие файлы не переписываются. Ошибки TOML/JSON, неизвестные поля и неверные значения содержат имя файла и поля. Целочисленные настройки требуют целых значений TOML: логические значения, дробные числа и числовые строки отклоняются. Операции задаются массивом строк.

База и `numbra.log` находятся в системном каталоге пользовательских данных. Обычный лог пишется на уровне DEBUG, а `-v` дополнительно показывает сообщения в stderr. Если seed не задан, для сессии создаётся новый случайный seed; он показывается пользователю и сохраняется вместе с результатами.

## Разработка

```bash
uv sync --all-groups
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy
uv build
uv tool install dist/numbra-1.0.1-py3-none-any.whl
numbra --version
```

Ядро не зависит от Typer и Rich и пригодно для использования без CLI. Живой обратный отсчёт реализован через Prompt Toolkit, SQLite и логирование используют стандартную библиотеку Python. Облачной синхронизации, аккаунтов, GUI и сетевого API нет.
