Numbra генерирует воспроизводимые примеры, проводит короткие этапы на время и хранит историю, личные рекорды и серию дней в локальной базе SQLite.

## Возможности

- **Воспроизводимые сессии.** Один и тот же seed даёт одни и те же примеры; примеры не повторяются в пределах сессии.
- **Три уровня сложности.** `easy`, `normal` и `hard` с понятными статичными профилями.
- **Этапы на время.** Медленные, обычные и быстрые этапы. Мягкий режим оставляет ввод открытым после лимита и снижает очки; `--strict` завершает попытку по истечении лимита.
- **Не только `+ − × ÷`.** Квадратные корни, тригонометрия, логарифмы, степени, тождества и **приёмы** устного счёта вроде `43 * 11` или `97 * 94` включаются по желанию.
- **Точные ответы.** Каждый ответ — целое число, проверка точной арифметикой; дроби вроде `3/4` тоже принимаются при вводе.
- **Осмысленный прогресс.** Оценки от S до D, личные рекорды для каждого набора настроек, среднее время верного ответа, рекомендация уровня и серия дней.
- **Всё локально.** Без аккаунтов, облака и сети.

## Установка

Требуется Python 3.13 или новее. Из каталога проекта:

```bash
uv tool install .
numbra --version
```

Либо скачайте `numbra-<version>-py3-none-any.whl` из ассетов релиза и выполните `uv tool install ./numbra-<version>-py3-none-any.whl`.

## Быстрый старт

Запустите `numbra` без аргументов в терминале, чтобы открыть интерактивный интерфейс на английском или русском: меню с тренировкой, результатами, настройками, приёмами и экспериментальным Funbox. Команды ниже остаются доступными для скриптов и быстрого использования.

```bash
numbra                           # интерактивный интерфейс
numbra challenge                 # шесть минут, три этапа, сложность normal
numbra challenge -d hard --strict
numbra challenge -o "*,/" -t 3   # только умножение и деление, три минуты
numbra challenge -o tricks       # приёмы устного счёта
numbra tricks                    # все приёмы с правилом и примером
numbra results                   # сессии, навыки, прогресс
numbra config list               # все настройки и их значения
numbra config set challenge.difficulty hard   # сохранить сложность по умолчанию
```

`Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется.

### Как выглядит сессия

```text
Stage 1/3 · slow · 9 examples
Example 1/27 · limit 17s
48 * 5 =
Correct · score 1.00
```

После последнего примера Numbra показывает оценку, Score, Accuracy, Time, результаты по этапам, серию дней и рекомендацию, если она доступна. Интерфейс программы выводится на английском.
