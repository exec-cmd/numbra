# Использование

## Установка и запуск

Требуется Python 3.13 или новее. Установите Numbra из каталога проекта:

```bash
uv tool install .
```

Запускайте тренировку в интерактивном терминале, а завершённые результаты просматривайте командой:

```bash
numbra challenge
numbra results
```

Справка доступна через `numbra --help`, `numbra --version` и `numbra challenge --help`. `Ctrl+C` отменяет тренировку; незавершённая сессия не сохраняется.

## Выбор тренировки

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `-t, --duration MINUTES` | 6 минут или значение из настроек | Целевая длительность; минимум 1 минута. |
| `-d, --difficulty LEVEL` | `normal` | `easy`, `normal`, `hard` или `very-hard`. |
| `-S, --seed INTEGER` | Значение из настроек или новый случайный seed | Повторяет ту же генерацию при совпадении остальных настроек. |
| `-o, --operations LIST` | `+,-,*,/` | Операции и темы через запятую: `+,-,*,/,sqrt,trig,log,power`; `^` означает `power`. |
| `-n, --stages INTEGER` | 3 или значение из настроек | Число этапов; минимум 1. |
| `--strict` | Выключен | По истечении лимита попытка сразу завершается. |
| `--cooldown SECONDS` | 2 секунды | Пауза между примерами, от 1 до 3 секунд. |
| `--advanced` / `--no-advanced` | Сохранённые настройки | Включить все операции и темы либо выключить настроенные дополнительные темы. |
| `--identities` / `--no-identities` | Сохранённая настройка | Отдельно включить или выключить формулы. |

Пример запуска:

```bash
numbra challenge --duration 6 --difficulty normal --seed 42 --operations +,-,*,/ --stages 3
```

Дополнительные темы по умолчанию выключены. Выберите их через `-o "sqrt,trig,log,power"`; `identities` включается параметром `--identities`. При `-o "sqrt"` каждый пример содержит корень, отдельных арифметических примеров не будет. В тематических заданиях используются выбранные базовые операции, а если они не указаны — все четыре. Тренировка должна быть достаточно длинной, чтобы вместить каждую выбранную тему; иначе программа сообщит минимальную длительность.

## Как проходит тренировка

Этапы повторяются в порядке `slow`, `normal`, `fast`; стандартные лимиты ответа — 15, 10 и 5 секунд. Этапы меняют темп, но не уровень сложности. Бонусы могут увеличить время на умножение, деление и степени. В обычном режиме ответ можно вводить и после лимита, но начисляемые очки уменьшаются после него и становятся нулевыми на двойном лимите. `--strict` сразу завершает попытку при тайм-ауте.

Уровни сложности используют фиксированные профили и не подстраиваются под предыдущие ответы. В арифметике действует стандартный приоритет операций, деление точное, отрицательные ответы допустимы. Дробь вводится точно, например `3/4`.

Наборы примеров конечны. Если подходящие задания закончатся, некоторые могут повториться; программа выведет предупреждение. Дополнительные темы тоже ограничены: корни точные, степени используют показатели 2 или 3, логарифмы и тригонометрические значения берутся из набора известных точных значений. Отдельные сочетания исключены, чтобы сохранить точность ответов; профили сложности также ограничивают результат.

## Просмотр и удаление результатов

`numbra results` показывает недавние завершённые тренировки и сводки по операциям, темам и уровням. Количество записей задаётся параметром `--limit`, например `numbra results --limit 20`.

Сравнение с прошлой тренировкой отображается только для сопоставимых настроек и версий генерации/подсчёта очков. Поэтому у старых записей может не быть сравнения с новой тренировкой.

Чтобы очистить историю, выполните `numbra results --reset` и подтвердите действие. В сценарии автоматизации добавьте `--yes`, чтобы пропустить подтверждение. Команда удаляет историю тренировок.
