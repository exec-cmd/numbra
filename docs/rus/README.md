# Руководство пользователя Numbra

Numbra — терминальная программа для тренировки арифметики на время. Начните с раздела [«Использование»](usage.md): там описаны установка, параметры тренировки и просмотр результатов. В разделе [«Настройка»](configuration.md) показано, как сохранить предпочтения между запусками.
