# Usage

## Install and start

Numbra requires Python 3.13 or newer. Install it from a project checkout with:

```bash
uv tool install .
```

Start a challenge in an interactive terminal and view completed sessions with:

```bash
numbra challenge
numbra results
```

Use `numbra --help`, `numbra --version`, or `numbra challenge --help` for command help. Press `Ctrl+C` to cancel a challenge; incomplete sessions are not saved.

## Choose a challenge

| Option | Default | Effect |
| --- | --- | --- |
| `-t, --duration MINUTES` | 6 minutes or saved setting | Target training length; minimum 1 minute. |
| `-d, --difficulty LEVEL` | `normal` | `easy`, `normal`, `hard`, or `very-hard`. |
| `-S, --seed INTEGER` | Saved seed or a new random seed | Repeats the same generated session when other settings match. |
| `-o, --operations LIST` | `+,-,*,/` | Select operations and topics: `+,-,*,/,sqrt,trig,log,power`; `^` also means `power`. |
| `-n, --stages INTEGER` | 3 or saved setting | Number of stages; minimum 1. |
| `--strict` | Off | A timeout immediately ends the attempt. |
| `--cooldown SECONDS` | 2 seconds | Pause between examples; accepts 1–3 seconds. |
| `--advanced` / `--no-advanced` | Saved settings | Enable all operations and topics, or turn off configured advanced topics. |
| `--identities` / `--no-identities` | Saved setting | Independently enable or disable numerical identities. |

For example:

```bash
numbra challenge --duration 6 --difficulty normal --seed 42 --operations +,-,*,/ --stages 3
```

Advanced topics are off by default. Use `-o "sqrt,trig,log,power"` to select them; `identities` is selected with `--identities`. With `-o "sqrt"`, every exercise includes a square root and there are no standalone arithmetic exercises. Topic exercises use the selected basic operations, or all four if none are listed. A challenge must be long enough to include every selected topic; otherwise startup tells you the minimum duration required.

## What to expect

A challenge has stages that cycle through `slow`, `normal`, and `fast`. Their default answer limits are 15, 10, and 5 seconds. The stages change timing, not the selected difficulty. Operation bonuses can add time for multiplication, division, and powers. In the default soft mode, you may continue entering an answer after the limit, but points decrease after the limit and reach zero at twice the limit. `--strict` makes timeout an immediate failed attempt.

Difficulty uses fixed profiles; it does not adapt to your past answers. Generated arithmetic follows standard precedence, division is exact, and negative answers are allowed. Enter fractions exactly as `numerator/denominator`, for example `3/4`.

The exercise collections are finite. If a session exhausts its selected collection, examples may repeat and Numbra displays a warning. Advanced topics also have bounded ranges: roots are exact square roots, powers use exponents 2 or 3, logarithms and trigonometric values come from supported exact-value sets, and some combinations are excluded to keep answers exact. Difficulty profiles also limit results.

## Review or clear results

`numbra results` shows recent completed sessions and summaries by operation, topic, and difficulty. Choose how many sessions to display with `--limit`, for example `numbra results --limit 20`.

A previous-session comparison appears only when the challenge settings and generator/scoring versions are comparable. Sessions generated by older versions may therefore have no comparison with a new session.

To clear saved results, run `numbra results --reset` and confirm the prompt. For a script, add `--yes` to skip confirmation. Reset removes training history.
